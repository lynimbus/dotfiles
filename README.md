# 你说得对，但是《NixOS》是一个独特的、社区研发的开源操作系统。这个系统建立在一个被称为"Nix"的强大包管理器之上。在这个系统中，所有的配置和包管理都通过Nix表达式来描述，这使得系统配置和包管理具有了高度的可复制性和原子性。你将扮演一位名为"用户"的角色，在自由的探索中邂逅各种强大的工具和应用，和它们一起解决问题，提高效率——同时，逐步发掘NixOS的真相。
